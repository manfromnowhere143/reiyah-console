    REFUTATION, and the reason it is structural rather than a fixture accident:
    c = a*n / [(a+b)(a+cc)] is monotonically DECREASING in b and in cc. Every
    maximiser therefore pushes both single-miss cells to their lower bound and
    every minimiser pushes both to their upper bound. The tie b == cc is satisfied
    at both extrema for free, so it can never bind. The formulation was vacuous
    for this estimand on every stratum, not just the symmetric one.
    It is retained here as a refuted design, not deleted.

================================================================================================
F-01c  PROPOSITION M4-1: c is invariant under proportional reference error
================================================================================================
  The second attempt encoded non-differential error as `the error lands in each
  cell in proportion to that cell's share of the stratum`. That is also wrong, and
  wrong in the opposite direction: it has NO identifying content at all.

  PROOF. c(a,b,cc,d) = a*n / [(a+b)(a+cc)] with n = a+b+cc+d. For any lambda > 0,
    c(la, lb, lcc, ld) = (la)(ln) / [(l(a+b))(l(a+cc))]
                       = l^2 * a*n / [ l^2 * (a+b)(a+cc) ]  =  c(a,b,cc,d).
  c is a ratio of a degree-two form to a degree-two form, hence scale invariant. A
  strictly proportional perturbation IS a scale by (1 + t), so c does not move. QED

    lambda= 0.90   cells (72.0, 1350.0, 360.0, 7218.0)   c=1.0549
    lambda= 1.00   cells (80.0, 1500.0, 400.0, 8020.0)   c=1.0549
    lambda= 1.15   cells (92.0, 1725.0, 460.0, 9223.0)   c=1.0549
    lambda= 2.00   cells (160.0, 3000.0, 800.0, 16040.0)   c=1.0549

  CONSEQUENCE, and it is the useful part. Uniform reference error does not bias c
  at all. Every unit of c's identification exposure comes from DIFFERENTIAL
  reference error, error whose rate depends on the cell and therefore on the
  channel outcomes. That relocates the whole M4 problem: a blinded reannotation
  does not need to estimate the overall error rate, which is irrelevant here. It
  needs to bound how much the error rate VARIES ACROSS CELLS.

F-01d  L2 restated a third time, as a bound on differentiality
================================================================================================
  Each cell j is perturbed at rate r_j in [rbar - delta, rbar + delta] for a free
  common rate rbar. delta = 0 recovers the vacuous proportional case; large delta
  recovers L1. delta is the quantity a blinded reannotation must actually bound.

    The width grows monotonically in delta, from exactly zero at delta = 0. This is
    the correct shape: the assumption now has identifying content, it is stated as
    a single reviewable number, and F-04's channel-dependent contamination is the
    case where delta is large and unknown rather than small and measured.

SUMMARY
================================================================================================
  PROPOSITION M4-1: c is scale invariant, so UNIFORM reference error does not
  bias it at all. Every unit of identification exposure is DIFFERENTIAL error.
  A blinded reannotation must therefore bound how much the error rate varies
  across cells, not the overall error rate, which is irrelevant to c.
  At delta = 0.05 the fixture stratum's set already covers 1.0, so a five point
  differential error rate is enough to leave its dependence unidentified.
  The ladder narrows only when an assumption actually binds. Two L2 formulations
  were refuted here, one vacuous and one null, and both are retained as refuted.
  Only L3 is headline eligible, and only after independent replication.
  Coordinated label error is invisible to marginals and visible only to a bound.
  A vanishing marginal yields UNBOUNDED, never a finite surrogate.
  Channel-dependent reference contamination yields `invalid`, never a wider set.
